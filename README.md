# 🎮 Tic Tac Toe Game

A simple and interactive **Tic Tac Toe** game built using **HTML, CSS, and JavaScript**. This project allows two players to play turn by turn with automatic win and draw detection.

## ✨ Features

* 🎯 Two-player gameplay
* 🏆 Win detection
* 🤝 Draw detection
* 🔄 Restart game option
* 📱 Responsive design
* 🎨 Clean and modern user interface

## 🛠️ Built With

* HTML5
* CSS3
* JavaScript (ES6)
